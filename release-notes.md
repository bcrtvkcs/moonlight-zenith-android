Welcome to the **Moonlight Zenith v1.1.0-zenith Release**!

## 🆕 What's New?
- **Fix (Turkish `ç` / `Ç` & Punctuation Mapping on Windows Hosts):** Resolved a long-standing issue where `ç` and `Ç` would not type on Windows hosts (Sunshine) even when the Turkish (`tr_TR`) keyboard layout was selected. Corrected the virtual key mapping for `ç`/`Ç` from `VK_OEM_5` (`0xDC`) to `VK_OEM_PERIOD` (`0xBE`, matching US scancode `0x34` -> Turkish Q `ç`), aligned `,`/`;` (`0xDC`) and `"`/`é` (`0xC0`), and swallowed synthetic `KEYCODE_ALT_LEFT` / `KEYCODE_ALT_RIGHT` events generated by Android's `Virtual.kcm` (`Alt+C` / `Shift+Alt+C`) on software keyboards (Gboard, Hacker's Keyboard, etc.) so Windows no longer intercepts the keystroke as an `Alt` shortcut or activates the window menu bar (`SC_KEYMENU`).
- **Unified Package Names & Labels Across Debug and Release:** Removed the `.debug` package suffix and `(Debug)` label suffix from debug builds. Both debug and release variants now share the exact same package identity (`com.limelight.zenith` for standard devices, `com.limelight.root.zenith` for rooted devices) and display name (`Moonlight Zenith`).
- **Unified Release Signing Across All 4 Variants:** Configured `debug` builds to sign with the release keystore (`signingConfigs.release`) so Debug and Release APKs can be installed interchangeably on top of each other without uninstalling.
- **Dynamic Git Tag & Commit Count Versioning (Gradle 9 Fix):** Replaced deprecated Groovy `execute()` calls with `ProcessBuilder` in `app/build.gradle` so `versionName` (latest `*zenith*` tag) and `versionCode` (git commit count) are dynamically resolved across all 4 APK variants.
- **Repository Hygiene:** Added `*.lnk` shortcut files to `.gitignore`.

## 🔄 Upstream Synchronization (Moonlight Android v12.2)
Merged all upstream changes from [Moonlight Android v12.2](https://github.com/moonlight-stream/moonlight-android/releases/tag/v12.2) while preserving all Moonlight Zenith features:
- **Android 15, 16 & 16.1 Keyboard Support:** Added support for Android 16.1 native keyboard capture, newer keycodes from Android 15/16, and fixed the missing `Shift` modifier for the `+` (`KEYCODE_PLUS`) key.
- **Video Streaming & Latency Improvements:** Disabled producer throttling on the video surface and disabled H.264 constraint / `level_idc` modifications on Android 8.0+ for lower latency and improved hardware decoder compatibility.
- **Controller & Rumble Fixes:** Fixed controller rumble not working due to a deprecated vibrator API call, fixed crashes/ANRs in controller LED handling, added Xbox Series S/X and 8BitDo controllers to the built-in Xbox One USB driver, and synced SDL joystick mappings.
- **Meta Quest Compatibility:** Updated `UiHelper` to avoid failing on Meta Quest devices.
- **Core Native Libraries & Toolchain Upgrades:** Updated `moonlight-common-c`, `libopus` (`1.6.1`), `OpenSSL` (`4.0.2`), `OkHttp` (`5.5`), `jMDNS`, and `BouncyCastle`; enabled core library desugaring to fix mDNS discovery on older Android versions; upgraded `compileSdk` to `37`, `targetSdk` to `36`, NDK to `r29`, AGP to `9.4.0`, and Java compatibility to `JDK 17`.
- **Localization Updates:** Added new language entries and updated Weblate translations across 18+ languages (including Turkish, German, French, Spanish, Italian, Japanese, Korean, Russian, Ukrainian, Dutch, Portuguese, Bulgarian, Hungarian, Indonesian, Latvian, Norwegian Bokmål, Tamil, and Esperanto).
